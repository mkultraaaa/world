🛡 Правила безопасности

  • Dashboard через VPN (приватная сеть)
  • CORS restricted к dashboard origin
  • Bearer token на всех write endpoints
  • Secrets в env vars LaunchAgent, НЕ в коде
  • Git backup не содержит секретов (redacted)
  • Агентам запрещён YOLO mode на production

🔄 Rollback стратегия

  • Level 1 (syntax) — агент должен починить сам
  • Level 2 (dashboard down) — auto restart через launchctl
  • Level 3 (API) — ждём recovery (5 сек)
  • Level 4 (tests) — rollback к checkpoint
  • Level 5 (visual) — warning, не блокирует
  • После 3 неудачных попыток → полный rollback
  • Если rollback не помог → CRITICAL алерт

📊 Метрики качества

  • Visual diff порог: 5% (динамика ~0.1-0.7%)
  • API тестов: 35+ endpoints
  • Playwright табов: 11 × 2 viewport
  • Watchdog частота: каждые 30 минут
  • Autofix попыток: 3 перед rollback
  • Backup: ежедневно на GitHub (02:00)
